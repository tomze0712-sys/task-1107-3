# 粉色小球跳跃游戏

## 快速开始

### 方法一：直接打开网页文件（最简单）
1. 点击右上角的 “Code → Download ZIP” 将项目下载到电脑，或使用 Git 克隆到本地。  
   - 如果是 ZIP 压缩包，请先解压。  
2. 在文件管理器中找到解压后的项目文件夹，双击 `index.html`（或右键选择“用浏览器打开”）。  
3. 浏览器会直接打开游戏页面，即可按提示按下空格键开始玩。

> **提示**：如果双击后浏览器没有反应，可以先打开浏览器，再使用“文件 → 打开”功能手动选择 `index.html`。

### 方法二：通过本地服务器运行（推荐给开发者）
1. 确认电脑已安装 [Python 3](https://www.python.org/downloads/)。Windows 用户安装时请勾选 “Add Python to PATH”。
2. 打开命令行：  
   - Windows：按下 `Win + R`，输入 `cmd` 并回车。  
   - macOS：打开“终端（Terminal）”。  
   - Linux：打开常用的终端应用。
3. 在终端中切换到项目文件夹（将下面的路径替换成你实际的文件夹位置）：
   ```bash
   cd 路径/到/粉色小球跳跃游戏
   ```
4. 启动临时服务器：
   ```bash
   python3 -m http.server 8000
   ```
   > 若命令行提示找不到 `python3`，可尝试使用 `python` 代替。
5. 打开浏览器访问 [http://localhost:8000/index.html](http://localhost:8000/index.html)，即可进入游戏。要停止服务器，在终端按下 `Ctrl + C`。

## 操作说明

- 按下空格键让左侧的粉色小球跳跃。
- 连续按空格可以实现连续跳跃，从而跃得更高或停留更久。
- 躲避从右侧不断出现的方块障碍，碰撞则游戏结束。
- 生存时间越长，得分越高，努力刷新最高分吧！
